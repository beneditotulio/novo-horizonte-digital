## 🎯 FLUXOS PRINCIPAIS FUNCIONAIS

### Fluxo 1: Admin - Configuração do Sistema
```
Admin Login
    ↓
Criar Área (Terreno Jovem, MT 50k, 24 meses)
    ↓
Criar Lote (Lote 01 na Área)
    ↓
Criar Terrenos em intervalo (600-650 = 51 terrenos em 2s)
    ↓
✅ Sistema pronto para clientes
```

### Fluxo 2: Cliente - Reservar Terreno(s)
```
Cliente Login / Registro
    ↓
Selecionar Categoria → Lote
    ↓
Ver Grid (terrenos 600-650)
    ↓
Clicar números: 600, 601, 610, 620 (4 selecionados)
    ↓
Preencher: Contacto alternativo + Comprovativo
    ↓
Enviar Reserva
    ↓
✅ Terrenos em status "Reservado" (bloqueados)
```

### Fluxo 3: Operador - Validar e Aprovar
```
Operador Login
    ↓
Ver "Reservas Pendentes" na tabela
    ↓
Clicar "Ver Detalhes" → Tabs com todos dados
    ↓
Revisar: Cliente → Terrenos → Financeiro → Contacto
    ↓
Clicar "Descarregar PDF"
    ↓
PDF pronto em 2.3 segundos ✅
    ↓
Clicar "Aprovar Contrato"
    ↓
✅ Terrenos mudam para "Ocupado"
✅ Cliente vê 24 parcelas de MT 32,000
```

### Fluxo 4: Cliente - Pagar Mensalidades
```
Cliente Login
    ↓
Dashboard → Seção "Minhas Mensalidades"
    ↓
Ver parcelas 1/24 até 24/24
    ↓
(Futuro) Submeter comprovativo
    ↓
✅ Operador valida
✅ Status muda para "Pago"
```

## 📚 COMO USAR

### 1. Instalar Backend
```bash
cd backend/NovoHorizonteDigital.API
dotnet restore
dotnet ef database update
dotnet run
# API em: https://localhost:5001
```

### 2. Instalar Frontend
```bash
cd frontend/novo-horizonte-app
npm install
npm start
# App em: http://localhost:3000
```

### 3. Fazer Login (Demo)
```
Admin:
  Email: admin@novo-horizonte.com
  Senha: Admin@123

Operador:
  Email: operador@novo-horizonte.com
  Senha: Operator@123

Cliente:
  (Criar novo via registro na app)
```

### 4. Testar

Seguir: [GUIA_DEMONSTRACAO.md](/GUIA_DEMONSTRACAO.md)
